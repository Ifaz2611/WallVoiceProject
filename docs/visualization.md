# Interactive Visualization Notebook

This document describes the interactive Jupyter notebook for visualizing WallVoice24BD project results.

## Overview

The `interactive_visualization.ipynb` notebook provides interactive, exploratory visualizations of the WallVoice24BD dataset and model results. Unlike the static PNG charts generated by `scripts/plot_results.py`, this notebook uses Plotly and ipywidgets to create fully interactive plots that you can zoom, pan, and explore dynamically.

## Prerequisites

Before using the notebook, ensure you have:

1. **Completed the training pipeline** - The notebook requires:
   - `metadata/images.csv` - Image inventory
   - `splits/train.csv`, `splits/val.csv`, `splits/test.csv` - Data splits
   - `outputs/model-selection.json` - Model selection results
   - `outputs/evaluation.json` - Test evaluation results
   - `outputs/test-predictions.csv` - Test set predictions

2. **Installed dependencies** - Install all required packages:
   ```bash
   python -m pip install -r requirements.txt
   ```

   The notebook requires these additional packages (already included in requirements.txt):
   - `plotly==5.24.1` - Interactive plotting library
   - `ipywidgets==8.1.5` - Interactive widgets for Jupyter
   - `notebook==7.3.2` - Jupyter notebook interface

## Getting Started

### 1. Activate your Python environment

If you created a virtual environment following the main training guide:

**Windows (PowerShell):**
```powershell
.\.venv\Scripts\Activate.ps1
```

If script execution is blocked:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

### 2. Start Jupyter Notebook

From the repository root:

```bash
jupyter notebook interactive_visualization.ipynb
```

Or use Jupyter Lab (if installed):

```bash
jupyter lab interactive_visualization.ipynb
```

### 3. Run the notebook

Execute cells sequentially by clicking "Run" or pressing `Shift+Enter`. The notebook will:
- Load the dataset and results
- Display interactive plots for each section
- Provide interactive widgets for exploration

## Notebook Sections

### Section 1: Dataset Overview
- **Purpose**: Explore the overall dataset composition
- **Visualizations**:
  - Interactive bar chart showing image count per collection area
  - Summary statistics table
- **Interactivity**: Hover to see area codes and exact counts

### Section 2: Data Split Distribution
- **Purpose**: Understand how data is split across train/validation/test sets
- **Visualizations**:
  - Grouped bar chart showing split distribution by area
  - Split percentage summary
- **Interactivity**: Toggle between splits, see exact counts on hover

### Section 3: Model Performance Comparison
- **Purpose**: Compare different feature extractors and baseline models
- **Visualizations**:
  - Side-by-side bar charts for Accuracy, Macro-F1, and Weighted-F1
  - Performance summary table
- **Models shown**:
  - KNN with raw pixels
  - KNN with HOG features
  - KNN with ResNet-18 embeddings
  - Logistic Regression (balanced)
  - Linear SVM (balanced)
  - Dummy classifier (most frequent)

### Section 4: Test Set Evaluation Results
- **Purpose**: Review final test set performance
- **Visualizations**:
  - Per-class performance bar chart (Precision, Recall, F1)
  - Summary metrics with misclassification count
- **Interactivity**: Compare performance across different areas

### Section 5: Interactive Confusion Matrix
- **Purpose**: Understand model predictions and confusions
- **Visualizations**:
  - Heatmap with row-normalized percentages
  - Hover tooltips showing percentage and raw count
- **Interactivity**: Zoom into specific areas, see exact values on hover

### Section 6: Interactive Image Gallery
- **Purpose**: Browse sample images from different areas
- **Visualizations**:
  - Grid of images from selected area
- **Interactivity**:
  - Dropdown to select collection area
  - Slider to control number of images displayed
  - Shows image IDs for reference

### Section 7: Hyperparameter Tuning Visualization
- **Purpose**: Explore how model performance varies with hyperparameters
- **Visualizations**:
  - Line plot showing CV Macro-F1 vs k-neighbors
  - Different lines for different PCA component values
- **Interactivity**: Hover to see specific hyperparameter combinations

### Section 8: Feature Extractor Comparison (Radar Chart)
- **Purpose**: Compare feature extractors across multiple metrics
- **Visualizations**:
  - Radar chart showing Accuracy, Macro-F1, Weighted-F1, CV Macro-F1
- **Interactivity**: Toggle extractors on/off, hover for exact values

### Section 9: Misclassified Images Viewer
- **Purpose**: Examine which images the model got wrong
- **Visualizations**:
  - Grid of misclassified test images
  - Shows true label, predicted label, and confidence score
- **Interactivity**:
  - Slider to navigate through misclassified images
  - View up to 12 images at a time

### Section 10: Validation vs Test Performance
- **Purpose**: Compare validation and test performance by area
- **Visualizations**:
  - Side-by-side bar charts for Precision, Recall, F1
  - Comparison table
- **Interactivity**: Identify areas where model generalizes well vs poorly

### Section 11: Summary Dashboard
- **Purpose**: Quick overview of key project statistics
- **Output**: Text summary with all important metrics

## Interactive Features

All Plotly charts support:
- **Zoom**: Click and drag to zoom into specific regions
- **Pan**: Use the pan tool to move around the plot
- **Hover**: Hover over elements to see detailed values
- **Toggle**: Click legend items to show/hide specific traces
- **Reset**: Use the reset button to return to original view
- **Download**: Click the camera icon to save as PNG

Widgets (dropdowns, sliders) allow you to:
- Change which data is displayed
- Adjust visualization parameters
- Navigate through large datasets

## Tips for Effective Use

1. **Start with the overview** - Sections 1-3 give you a good understanding of the dataset and model performance
2. **Focus on areas of interest** - Use the confusion matrix to identify problematic areas, then explore those areas in the image gallery
3. **Check generalization** - Compare validation vs test performance (Section 10) to see if the model is overfitting
4. **Examine mistakes** - The misclassified images viewer (Section 9) helps understand model weaknesses
5. **Save interesting views** - Use the download button on plots to save specific visualizations

## Troubleshooting

### Notebook won't open
- Ensure Jupyter is installed: `python -m pip install notebook`
- Try Jupyter Lab instead: `python -m pip install jupyterlab`

### Plots not displaying
- Ensure all dependencies are installed: `python -m pip install plotly ipywidgets`
- Restart the Jupyter kernel after installing packages
- Try running: `jupyter nbextension enable --py widgetsnbextension`

### Images not loading
- Verify image folders exist in the repository root:
  - `Azimpur-Nilkhet/`
  - `BaileyRoad-Viqarunnisa/`
  - `Buet-Palashi/`
  - `Dhanmondi/`
  - `DU-Shahbagh/`
  - `Mirpur-Uttara-Tejgaon/`
- Check that paths in `metadata/images.csv` are correct

### Results not loading
- Ensure you've completed the training pipeline:
  ```bash
  python scripts/train_knn.py
  python scripts/evaluate.py
  ```
- Verify these files exist in `outputs/`:
  - `model-selection.json`
  - `evaluation.json`
  - `test-predictions.csv`

### Widgets not working
- If using Jupyter Notebook (not Lab), enable widgets:
  ```bash
  jupyter nbextension enable --py widgetsnbextension
  ```
- Restart the kernel after enabling
